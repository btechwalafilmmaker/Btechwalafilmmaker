The story.

Four years as a software engineer at TCS. Code by day, weddings on weekends. Eventually, the camera won.

Today I run WedFilmers, a wedding films studio in Delhi — and document the journey of an engineer turned filmmaker. DIY grading rigs, automated edit pipelines, and the craft behind every frame.

The engineering never left. It just changed lenses.
